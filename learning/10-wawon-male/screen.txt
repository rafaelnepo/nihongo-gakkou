わをん（フィナーレ）— SCREEN TEXT  (the video)
learning/ strand. Correct orthography, ALL HIRAGANA, no romaji, no gloss.
No kanji, so nothing to furigana — the whole line is decodable kana, the skill being taught.

The wa-row is the LAST row and it is SPECIAL: only わ starts words; を is only the object particle
(always read "o", F-16); ん never starts a word — it ENDS them. So this is not a 3-theme song
but the SERIES FINALE — a graduation "last sounds" song, rendered in all three house voices
(Strategy B, personas.md). Refrain: わ を ん.
  · SHORT (~0:45, vertical Stories/Reels) = PART 1 (the わ teach) only  → suno-v2.txt
  · YOUTUBE (~2:00) = PART 1 + を + ん + the whole-gojuon REVIEW  → suno-v3.txt (this screen)

LAYOUT INTENT (stage 8): show the WORD big + its Irasutoya picture, then the SENTENCE with
the target word HIGHLIGHTED as the ball reaches it. In the を / ん beats, blow up the single
kana (を, then ん) as the "sound of the day". In the REVIEW, flash each word's EARLIER
illustration — one per row, あ→ら — the "you can read them all now" wall.
