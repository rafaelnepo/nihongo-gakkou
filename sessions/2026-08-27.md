# 2026-08-27 — genesis: songs → Remotion engine → its own published repo

Previous: — (first session)

The project was born this day, inside `Irasutoya/songs/`, and ended the day as
its own published repo with a live site. Long session; this is the map.

## What happened
- **Two personal songs written** (private, family): `te-extrano` (for his wife —
  bachata × Japanese) and `onaji-tsuki` (for his son — a music-box lullaby).
  The lullaby was generated and got a full **sing-along lyric video**.
- **Built the Remotion lyric-video engine** (`video/`): a parametric template
  (zod schema, `calculateMetadata` auto-duration, `@remotion/layout-utils`),
  karaoke per-character light-up + a bouncing red ball, a night-sky background.
  One template renders every song via a registry.
- **Built the WhisperX forced-aligner** (`tools/align/`): known-lyrics alignment →
  per-character timings, with a `debunch` pass for held/sustained notes. Proved on
  the lullaby (199/199 chars anchored).
- **Built the HTML output system**: per-song `sheet.html` **generated** from
  `song.json` + the `.txt` sources by `tools/build_sheets.mjs`, a filterable
  **dashboard** (`index.html`), and a **music glossary** (`reference/`).
- **Designed the first learning song, `03-aiueo`** (gojuon row 1): went from
  words-only (v1) → **contextual** word→sentence (v2) → a **3-minute** teach →
  day-bridge → review cut (v3). Ran a **voice audition** across styles.
- **Split the whole thing out of Irasutoya** into
  `~/Desktop/claude-projects/2-medium-priority/nihongo-gakkou/`, made it a
  standalone repo, and **published**: GitHub repo, GitHub Pages, and a CI Action
  that auto-runs the generator on push.
- **Wrote the Comprehensible Input principles** doc grounding the pedagogy.

## Decisions
- **House voice = city-pop female** (Persona to be made from the winning take).
  koto×male and lo-fi are kept for other/moodier content. (findings F-11)
- **Comprehensible input from song 1** — teach words *in context* (word→sentence),
  never bare lists. (README guiding principle; `reference/comprehensible-input.md`)
- **Duration standard**: ~1:00 vertical (Reels) · ~3:00 YouTube, the long cut
  filled with *sentences* not a loop. (house-style.md; findings F-12)
- **Privacy**: `personal/` (family songs) and `books/` (copyrighted Krashen PDFs)
  are **git-excluded**; the dashboard drops private songs; family names scrubbed
  from public docs; the engine's public demo is a neutral `aiueo-demo`, not the
  family lullaby.

## Key findings logged (see `findings.md`)
- **F-10** — a list of same-onset words *blends*; put words in sentences (also
  better pedagogy = i+1).
- **F-11** — voice audition: city-pop female wins for the basic songs.
- **F-12** — Suno performs pasted lyrics **once**; length is predictable from
  lyric quantity, so reach 3 min by adding a bridge+review, not a loop.
